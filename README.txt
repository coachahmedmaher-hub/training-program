طريقة النشر على GitHub Pages:

1) أنشئ Repository جديد على GitHub.
2) ارفع index.html ومجلد pages بالكامل.
3) افتح Settings ثم Pages.
4) تحت Build and deployment اختر Deploy from a branch.
5) Branch = main، Folder = / (root)، ثم Save.
6) انتظر قليلًا وسيظهر رابط الموقع.

مهم: الـPDF الأصلي غير موجود داخل هذه الحزمة. الصفحات معروضة كصور.
الحماية تمنع/تصعّب النسخ والحفظ والطباعة من الواجهة، لكنها لا تمنع Screenshot أو أدوات المطور بشكل مضمون.
